<h1>Financial Literacy Calculations</h1>

<p>
This repository contains the Financial Literacy Calculations web application for the ClassResources platform.
It is an interactive educational tool designed to help students learn and practice financial concepts through real-time calculations.
</p>

<hr>

<h2>Live Website</h2>

<p>
<a href="https://calculations.classresources.ca/" target="_blank">
https://calculations.classresources.ca/
</a>
</p>

<h2>Overview</h2>

<p>
The Financial Literacy Calculations project is part of the ClassResources educational ecosystem.
It focuses on helping students understand financial concepts such as budgeting, basic calculations, and money-related problem solving through an interactive interface.
</p>

<p>
The application is designed to make financial learning more practical by allowing users to input values and immediately see calculated results.
</p>

<h2>Features</h2>

<ul>
  <li>Interactive financial calculation tools</li>
  <li>Real-time input-based updates</li>
  <li>Clean and responsive user interface</li>
  <li>Educational focus on financial literacy concepts</li>
  <li>Fast and optimized performance using Vite</li>
</ul>

<h2>Built With</h2>

<ul>
  <li>React</li>
  <li>Vite</li>
  <li>JavaScript</li>
  <li>Tailwind CSS</li>
  <li>PostCSS</li>
</ul>
