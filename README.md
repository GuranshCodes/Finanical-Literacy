# Financial Literacy

This repository contains a React + Vite web app for financial literacy dashboards and analytics.

## Getting Started

1. Clone the repository.
2. Navigate to the project directory.
3. Install dependencies: `npm install`
4. Create an `.env.local` file and set the environment variables below.

```
VITE_APP_ID=your_app_id
VITE_APP_BASE_URL=your_backend_url
```

Run the app locally with:

```bash
npm run dev
```

## Build

Create a production build with:

```bash
npm run build
```

## Environment

- `VITE_APP_ID` – app identifier used by the backend
- `VITE_APP_BASE_URL` – backend API base URL

## Notes

This app is built with React, Vite, Tailwind CSS, and Recharts.
